# 概念与关系词典

已确认业务骨架的标准术语。正式定义以同目录sidm.ttl为准。

| 对象 | 标准IRI末段 | 含义 |
|---|---|---|
| 产品 | Product | 持续建设、使用和维护的数字化对象 |
| 需求 | Requirement | 希望解决的问题或实现的改变 |
| 项目 | Project | 由需求转化而来、组织实施的建设工作 |
| 项目阶段 | ProjectStage | 按需划分的项目实施过程 |
| 关键事项 | KeyItem | 阶段内需要关注的重要工作节点 |
| 任务及子任务 | Task | 具体执行工作及其拆分；子任务仍是任务，通过父任务关系表达 |
| BUG | Bug | 建设过程中的软件缺陷记录 |
| 项目合同 | ProjectContract | 项目建设中的商务约定 |
| 付款阶段 | PaymentStage | 项目合同金额的分阶段安排 |
| 付款记录 | PaymentRecord | 实际付款后登记的金额、月份及经办信息 |
| 产品运维合同 | MaintenanceContract | 产品持续运维服务的商务约定 |
| 运维工单 | WorkOrder | 产品使用中的问题处理记录 |
| 供应商 | Supplier | 提供建设或运维服务的合作方 |
| 人员 | Person | 承担具体业务责任和参与工作的人员 |

| 关系 | 标准IRI末段 | 出发对象 → 目标对象 |
|---|---|---|
| 归属产品 | belongsToProduct | Requirement, Project, WorkOrder, MaintenanceContract → Product |
| 来源需求 | sourceRequirement | Project → Requirement |
| 直接归属需求 | belongsToRequirement | Task, Bug → Requirement |
| 直接归属项目 | belongsToProject | Task, Bug → Project |
| 阶段归属项目 | stageProject | ProjectStage → Project |
| 事项归属阶段 | itemStage | KeyItem → ProjectStage |
| 父任务 | parentTask | Task → Task |
| 合同归属项目 | contractProject | ProjectContract → Project |
| 付款阶段归属合同 | stageContract | PaymentStage → ProjectContract |
| 付款记录归属阶段 | recordStage | PaymentRecord → PaymentStage |
| 供应商 | supplier | ProjectContract, MaintenanceContract → Supplier |
| 续签自 | previousContract | MaintenanceContract → MaintenanceContract |
| 负责人 | owner | Product, Requirement, Project, KeyItem → Person |
| 任务负责人 | taskOwner | Task → Person |
| 项目成员 | member | Project → Person |
| 事项协作人 | collaborator | KeyItem → Person |
| BUG处理人 | assignee | Bug → Person |
| 工单跟进人 | follower | WorkOrder → Person |
| 付款经办人 | handler | PaymentRecord → Person |
| 提出人 | submitter | Requirement, WorkOrder → Person |

另有两条明确推导关系：`hasProject`是`sourceRequirement`的逆关系；`relatedProduct`通过任务或BUG的直接归属追溯产品，不改变直接归属。所有IRI使用工程命名空间`urn:sidm:ontology:`，不声称已注册或发布为企业公共词汇。

## 当前数量、任务与终止口径

一需求至多一个项目、一项目至多一份项目合同、续签链不分叉，在SHACL中表达当前SIDM限制。主子任务直接归属同一个需求或项目，当前只支持两层。运维合同的有效结束日期在提前终止时采用终止日期，否则采用约定服务结束日期。上述数量口径已由用户逐项确认。运维合同录入即表示已付款，无单独付款阶段与明细。
