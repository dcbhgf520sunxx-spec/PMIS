# 标准本体必须回答的问题

这是验证标准，不是由程序运行后倒推出来的预期答案。示例均为虚构，真实数据另存。

| 问题 | 已知输入 | 预期结果 | 机制 |
|---|---|---|---|
| 项目来源于哪个需求 | 项目→需求→产品 | 保留显式关系，需求与项目状态独立 | SPARQL |
| 任务可以追溯哪个产品 | 任务→项目→产品；未输入任务→产品 | 推理得出relatedProduct，不增加任务直接归属需求 | OWL属性链 + HermiT |
| 需求承接了哪个项目 | 只输入项目sourceRequirement需求 | 推理得到需求hasProject项目 | OWL逆属性 + HermiT |
| 合同已付、待付多少 | 100000合同，计划100000，付款30000 | 已付30000，待付70000；阶段部分付款 | SPARQL十进制汇总 |
| 已修复BUG算不算关闭 | BUG状态已修复 | 单列待关闭 | SPARQL |
| 项目没记录来源需求 | 删除对应关系 | OWL保持可一致；SHACL报告缺项 | 两种标准工具分别运行 |
| 两类阶段能否混同 | 同一对象同时是项目阶段和付款阶段 | 推理器报告不一致 | OWL互斥类 + HermiT |
| 续签开始早于上期有效结束 | 构造日期重叠 | SHACL报告错误 | SHACL-SPARQL |
| 单笔付款0或阶段超付 | 构造错误金额 | SHACL报告错误 | SHACL数据类型及聚合约束 |
| 实例能否同时归属需求与项目 | 给任务追加第二种直接归属 | SHACL报告错误 | SHACL排他分支 |

身份：环境、类型与源记录ID组成IRI，同名不合并；不同已知记录使用OWL AllDifferent明确区分。日期：日粒度映射为UTC零点xsd:dateTime，仅作日历编码，不表示实际发生在零点；月份保留YYYY-MM字符串。此选择避免给HermiT输入OWL2标准数据类型之外的xsd:date/gYearMonth，并在映射说明中保留源粒度。

2026-10-09新增反例：提前终止后的合法续签应通过；终止日期超出服务期间、无终止原因、子任务跨归属、三级任务、主任务完成但子任务未完成、需求前期状态跨类型、同一需求多个项目、同一项目多合同、续签链分叉应报告问题。付款计划与合同金额不符时，相关答案必须标记“异常待核实”。
