# 需求转项目优化交付单

## 变更内容

- 需求列表、详情提供“转项目”；任何未关联项目的需求状态均可转换，自动带入来源需求、产品、标题及负责人。已关联后隐藏转换与普通状态变更操作，详情基本信息展示关联项目链接。
- 新建项目关联需求和需求转项目使用同一个项目创建接口，成功后将需求置为 `36 已转项目`。原需求内容、完成信息、附件和历史保留。
- 删除项目保留既有任务、BUG、合同限制；有关联需求时必须选择原需求恢复状态。换绑时同样必须选择原需求恢复状态，新需求更新为已转项目。所选状态按需求路径校验，完成、暂停附加信息仍必填。
- 创建、删除、换绑涉及的需求、项目及历史在同一事务内执行；使用行锁及唯一约束防止重复关联，普通需求更新通过状态条件防止覆盖并发转换结果。
- 已转项目排除需求逾期、待办、计划待完成和缺失计划日期提示；状态分布单列。MCP 和开放接口中文状态同步；i8 不覆盖已转项目状态及关联产品。
- 复用统一列表、详情、表单、删除确认及状态控件。删除确认内表单错误只显示字段提示；工作台补充含必填表单的删除示例。审计支持并验证业务删除包装必须直接调用公共删除组件。
- 无新增菜单或权限；转换使用项目权限，MCP 保持原菜单、负责人和 preview/execute 契约。项目换绑/删除参数新增可选对象 `requirement_release`，有关联需求时业务校验为必填。
- 无表、字段、索引或关联结构调整。新增数据迁移 `20260921_01_requirement_project_transfer.sql`，同步初始化状态说明、数据库说明、MCP 文档与版本记录 `v2026.09.21.3`。
