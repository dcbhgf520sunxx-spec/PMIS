# 个人单据完成率 MCP

用户已确认业务本体与 MCP 各自职责并授权实现。本体维护完成含义、责任角色、归期及证据规则；MCP读取授权真实数据并执行计算。规则来源为[个人完成率统计规则](../个人完成率统计规则.md)。

## 变更内容

- 页面/组件：本次计算能力不涉及前端组件；此前本体页面的完成率口径只解释规则。
- 接口/权限/菜单：新增 Query `business_completion_analysis`，接入 catalog、严格输入输出 Schema、公开工具解析、dispatcher、动态业务权限和既有审计；不新增菜单、按钮或人员权限。Action和已有周期统计不变。
- 数据库：无表、字段、索引或关联结构变更，无 migration；真实验证使用随机隔离结构，不改现有业务单据。
- 返回人员和类别的统计数、完成数、百分比、已知数量、排除数、待核实数；明细附单据、归期原因、关联单据及历史依据。完整聚合不受分页影响，续页数据变化明确拒绝。
- 当前责任角色和最新计划日期；主子任务按个人去重、历史观察日创建边界、需求否定结论及重评、暂停参与、上级关闭、逾期遗留、BUG激活去重均有覆盖。阶段只汇总事项，不推定个人负责人或计划日期。
