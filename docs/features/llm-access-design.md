# 模型中心方案（2026-10-12 已确认）

## 目标和页面

增加“基础设置 → 模型中心”，地址 `/model-connections`。管理员在页面维护模型配置，数字孪生 AI 总结读取启用的默认配置，保存后无需重启服务。首版支持 DeepSeek 和采用相同 Chat Completions 协议的服务，不实现其他协议适配、自动切换或多模型调度。

页面复用 TemplateListPage、TemplateFormPage、TemplateDetailPage、AdminPasswordInput、StatusConfirmAction、AdminAsyncTaskStatus 等已有组件。列表展示名称、供应商、模型、默认标记、启停状态、创建人和创建时间；提供新增、编辑、启停、设置默认和测试连接。测试使用固定短文本，不发送业务记录。

菜单和后端管理接口使用 `/model-connections` 独立权限，默认仅授予管理员，后续由角色管理授权。数字孪生用户不需要模型管理权限，仍只按自己的业务权限生成总结，不能读取模型配置或密钥。

## 建议数据库结构

新增 `pms_llm_connection`：

| 字段 | 类型和约束 | 含义 |
| --- | --- | --- |
| id | BIGSERIAL，主键 | 配置编号 |
| name | VARCHAR(100)，非空 | 接入名称 |
| provider | VARCHAR(100)，非空 | 供应商名称 |
| base_url | VARCHAR(500)，非空 | HTTPS 服务地址 |
| model_name | VARCHAR(100)，非空 | 模型标识 |
| api_key_ciphertext | TEXT，非空 | 加密后的 API 密钥，包含解密所需随机数和校验信息 |
| enabled | SMALLINT，默认0，只能0/1 | 停用/启用 |
| is_default | SMALLINT，默认0，只能0/1 | 是否默认模型 |
| timeout_seconds | INTEGER，默认30，范围5至60 | 请求超时 |
| creator_id / updater_id | BIGINT，可空，外键关联 pms_user(id)，删除用户时置空 | 创建人/更新人 |
| created_at / updated_at | TIMESTAMPTZ，默认NOW() | 创建/更新时间 |

增加部分唯一索引，保证 `is_default=1` 最多一条；增加检查约束，默认模型必须启用。设为默认时事务内取消旧默认；停用默认模型同时取消默认标记，操作确认明确告知影响。保存模型参数或替换密钥后使相关总结缓存失效。

现有业务表和数据不变，不自动复制本地模型密钥到任何其他环境。迁移只新增配置表、二级菜单及管理员授权；不自动写入真实模型配置。同步初始化SQL、增量迁移、数据库结构Markdown/Excel、后端接口和测试。

## 密钥和调用

API密钥只通过保存接口传入后端，采用AES-256-GCM加密，不回显，不写操作日志、异常日志或版本记录。编辑时留空保留原密钥，输入新值才替换。加密主密钥由部署流程在服务共享目录一次生成并保留，不随Git或发布包分发；本地使用忽略的私有文件。部署流程负责文件权限和服务读取，页面不展示加密主密钥。

服务地址保存和调用时校验，禁止带凭据的URL、非HTTPS协议和指向本机/内网的地址；禁止自动跟随重定向，避免密钥或业务数据发往非预期地址。业务调用只使用服务端已保存配置，不允许前端传入调用地址或提示词。

仅在尚无任何页面配置时保留现有服务端环境变量的兼容方式。一旦创建页面配置，业务调用只使用启用的默认模型；默认模型停用或未选择时显示清晰中文提示，不自动回退到旧环境变量。模型管理的保存、启停和设默认按已有审计能力记录真实变更；密钥字段只记录“已更换”，不记录密钥内容。
